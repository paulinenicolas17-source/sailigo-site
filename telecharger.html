Télécharger Sailigo

L'application n'est pas encore publiée sur les magasins d'applications. Elle s'installe directement, et tu recevras les versions suivantes de la même façon.

Android

Télécharger Sailigo pour Android

  1. Touche le bouton ci-dessus depuis ton téléphone Android. Le téléchargement démarre tout de suite.
  2. Ton navigateur peut prévenir que ce type de fichier « peut être dangereux » : c'est le message affiché pour toute application installée hors magasin. Choisis de conserver le fichier.
  3. Ouvre le fichier téléchargé. Android demandera l'autorisation d'installer des applications depuis cette source : accepte, puis reviens en arrière et relance l'installation.
  4. Ouvre Sailigo et crée ton compte.

Ces avertissements sont normaux : ils s'affichent pour toute application installée hors magasin. Ils disparaîtront quand Sailigo sera publiée sur Google Play.
